백업 / 롤백

중간 수정본이 아니라, 관리자가 “작업 완료 저장”을 누른 시점을 하나의 운영 스냅샷으로 남깁니다.

✅ 작업 완료 저장

여러 수정 작업을 마친 뒤 누르는 운영 체크포인트입니다.\n곡 DB, 주일기록, 악보 버전 테이블, 로컬 설정을 JSON 스냅샷으로 저장합니다.\n악보 이미지 파일 자체는 포함하지 않고, 파일 경로/악보 기록만 포함합니다.
-찬양곡
-주일기록
-악보버전
-악보파일

🧭 롤백 원칙

전체 롤백은 선택한 스냅샷으로 운영 데이터를 되돌리는 강한 작업입니다.\n그래서 롤백 직전 현재 상태를 자동 백업으로 먼저 저장합니다.\n복원은 관리자 확인 체크 후에만 실행됩니다.
테이블 상태 확인 전입니다.

📚 저장된 스냅샷

브라우저에 저장되는 빠른 롤백 목록입니다. 용량이 큰 경우 저장이 제한될 수 있으므로 중요한 시점은 JSON 다운로드도 함께 해두는 것이 안전합니다.

📥 JSON 가져오기 / 복원

백업 JSON을 불러와서 안전 복원 또는 전체 롤백에 사용할 수 있습니다.\n안전 복원은 기존 데이터를 지우지 않고 추가합니다.
준비됨.
