드림찬양단 worship-db 최종 적용 안내

업로드/교체할 파일:
1. index.html  - PC/모바일 선택 입구 화면
2. pc.html     - 기존 PC 관리 화면 보존 + 모바일/연주 모드 이동 버튼 + 상단 통계 카드 필터
3. mobile.html - 태블릿/모바일 통합 화면 + 연주 모드 + 전체악보 관리

적용 순서:
1. GitHub 저장소 worship-db 접속
2. 위 3개 파일을 루트 경로에 업로드/교체
3. Commit changes 클릭
4. Vercel 자동 배포 완료까지 기다림
5. 아래 주소 확인

주소:
- 선택 화면: https://worship-db-sable.vercel.app/
- PC 관리: https://worship-db-sable.vercel.app/pc.html
- 모바일/연주: https://worship-db-sable.vercel.app/mobile.html

이번 업데이트 내용:
- PC 화면 상단 통계 카드 클릭 시 아래 찬양곡 목록이 해당 곡으로 필터됨
  사용 이력 / 악보 완료 / 전체 / 작업예정·악보없음 / 영상 있음
- PC 화면 상단에 모바일·연주 모드 이동 버튼 추가
- 모바일 화면에서 PC 관리 화면 이동 유지
- 모바일 악보보기를 '연주 모드'로 정리
- 연주 모드에서 악보 좌우 스와이프 시 이전곡/다음곡 이동
- 연주 모드 상단에 콘티 미니 리스트 표시
- 연주 모드에 이전곡/다음곡 이름 표시
- 악보 없는 곡은 '악보 업로드 예정'으로 표시
- 전체악보 업로드/보기/삭제 유지

주의:
- Supabase Storage의 scores 버킷 권한이 막혀 있으면 전체악보 업로드가 실패할 수 있음
- 파일 교체 전 현재 GitHub 상태를 한 번 백업하면 안전함
