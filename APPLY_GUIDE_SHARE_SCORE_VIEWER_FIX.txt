공유화면 악보/연주화면 추가 수정 안내

기준: worship-db-phase6-mobile-overlay-share-button-fix.zip
수정 파일: share.html

변경 내용:
1. 공유 페이지에서 각 곡 카드에 [악보 보기], [연주화면] 버튼 추가
2. 공유 페이지 상단에 [공유 연주화면 보기] 버튼 추가
3. 공유용 전체화면 악보 뷰어 추가
   - 왼쪽 위: 1장보기 / 2장보기
   - 오른쪽 위: X
   - 하단: 콘티 곡 제목 링크
   - 오른쪽 아래: 화면잠금
4. 스와이프 페이지 이동 유지
   - 마지막 페이지 다음 스와이프: 다음 곡
   - 첫 페이지 이전 스와이프: 이전 곡
5. 읽기 전용 공유 페이지이므로 수정/삭제/콘티편집 기능은 추가하지 않음

기존 기능 영향:
- mobile.html, pc.html은 건드리지 않음
- 공유 버튼 생성 로직은 유지
- share.html 내부 표시 기능만 확장

주의:
- 공유화면에서 악보가 보이려면 Supabase Storage의 scores/{songId}/ 경로에 공개 이미지가 있어야 함
