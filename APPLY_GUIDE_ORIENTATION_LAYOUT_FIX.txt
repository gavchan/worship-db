# 세로/가로 연주모드 레이아웃 분리 수정본

교체 파일:
- mobile.html
- mobile-portrait.html
- mobile-landscape.html

수정 내용:
1. 세로 연주모드
   - 상단 제목바 유지
   - 악보 1장 집중 표시
   - 하단 미니 콘티바 표시
   - 하단 이전/다음곡, 페이지 이동 버튼
   - 세로 한 화면 고정형 레이아웃

2. 가로 연주모드
   - 상단 제목바 숨김, 우측 상단 X만 표시
   - 악보 영역을 최대화
   - 기본 2장 보기
   - 하단 정보바에서 1장/2장 전환 가능
   - 좌우 스와이프는 현재 곡 페이지 이동

3. 공통
   - 연주모드 시작 시 세로/가로 선택 팝업 유지
   - 화면 방향 고정 시도 유지
   - 화면 꺼짐 방지 유지
   - X 종료 시 방향 고정/전체화면 해제 시도

확인 주소:
- /mobile.html
- /mobile-portrait.html
- /mobile-landscape.html
