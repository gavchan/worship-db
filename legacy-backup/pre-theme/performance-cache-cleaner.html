🧽 연주/공유 캐시 정리

공유 화면이나 연주 화면 아래쪽에 곡명만 남는 유령 항목, 없는 곡 ID, 빈 곡명, 같은 곡 중복 배열을 정리합니다. 기존 악보/곡 데이터는 삭제하지 않고 콘티 배열과 브라우저 임시값만 정돈합니다.

권장 순서: 점검하기 → 정리 실행 → PC/모바일 화면 강력 새로고침. 실제 악보 이미지는 삭제하지 않습니다.
-점검 콘티
-수정 필요
-브라우저 캐시
-정리 완료

1. 콘티/공유 데이터 점검

DB의 worship_history 배열에서 빈 곡명, 없는 song_id, 같은 song_id 중복, 같은 기본 곡명 중복을 찾습니다.

2. 이 브라우저 임시값 정리

현재 브라우저에 남은 콘티 override, 선택된 setlist, 연주 위치 같은 찌꺼기만 지웁니다. AI 설정과 테마는 보존합니다.
