Phase33 - 악보 버전 관리 정리

변경 내용:
- score-version-manager.html을 실제 악보 연결 관리 화면으로 재구성.
- 파일명 변경 없음. Storage 파일명은 기존 숫자/안전 파일명 유지.
- DB에서 곡/Key/버전/페이지 연결만 관리.
- 버전/페이지 탭, 미분류 악보 탭, 점검/복구 탭 추가.
- 기본/전주1/전주2 자동 생성 버튼 추가.
- Storage에는 있지만 DB 연결이 없는 악보를 선택해 버전으로 이동 가능.
- DB에는 있는데 Storage에 없는 깨진 연결 점검 및 DB 연결만 제거 가능.
- 선택 삭제 시 실제 Storage 파일 삭제 또는 DB 연결만 삭제 선택 가능.
- 페이지 번호 재정렬 기능 추가.

주의:
- phase2b_schema.sql이 Supabase에 실행되어 있어야 합니다.
- 이 도구는 파일 자체 편집기가 아니라 파일과 곡/버전 연결을 정리하는 도구입니다.
