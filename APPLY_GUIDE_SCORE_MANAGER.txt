드림찬양단 찬양 DB 업데이트 안내

이번 버전에서 바뀐 점
1. mobile.html
   - 관리도구 안에 곡별 악보 관리 실제 기능 추가
   - 곡 선택 후 JPG/PNG 여러 장 업로드
   - 업로드된 곡별 악보 보기/삭제
   - 삭제 후 악보가 0장이 되면 has_score=false로 갱신
   - 업로드 후 악보 상태가 자동 반영됨

2. pc.html
   - 관리도구의 외부 도구들이 새창이 아니라 같은 화면 안의 프레임으로 열림
   - 프레임 안에서 작업 후 닫기 가능
   - 필요하면 '새 탭으로 열기' 버튼으로 기존 방식도 가능

업로드할 파일
- index.html
- pc.html
- mobile.html

권장 확인 순서
1. https://worship-db-sable.vercel.app/ 접속
2. PC용 열기 → 관리도구 → 악보 업로드가 같은 화면 안에서 열리는지 확인
3. 모바일용 열기 → 관리도구 → 곡별 악보 관리
4. 곡 선택 → 이미지 업로드 → 악보 보기 → 삭제 테스트

주의
- Supabase Storage scores 버킷 업로드 권한이 막혀 있으면 업로드가 실패할 수 있음
- 이 경우 Supabase Storage 정책을 확인해야 함
