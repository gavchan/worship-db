드림찬양단 모바일 통합판 적용 안내

이번 수정본의 핵심:
- mobile.html 안에서 찬양곡 추가/수정/삭제 가능
- mobile.html 안에서 주일 기록 추가/수정/삭제 가능
- 모바일 관리도구가 PC 화면 링크로 넘어가지 않음
- 기존 index.html PC 화면은 그대로 유지

업로드 방법:
1. 압축을 풉니다.
2. GitHub worship-db 저장소에 들어갑니다.
3. mobile.html 파일을 기존 파일과 교체합니다.
4. APPLY_GUIDE.txt는 업로드하지 않아도 됩니다.
5. Commit changes를 누릅니다.
6. Vercel 자동 배포 후 아래 주소로 확인합니다.

확인 주소:
https://worship-db-sable.vercel.app/mobile.html

주의:
- 전체악보 업로드/곡별 악보 업로드는 다음 단계에서 DB/스토리지 구조를 맞춰 추가하면 됩니다.
- 나중에 모바일 통합판을 메인으로 쓰려면 mobile.html 이름을 index.html로 바꾸면 됩니다.
