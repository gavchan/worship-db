드림찬양단 1차 업데이트 적용 안내

교체/추가할 핵심 파일:
1. index.html
2. pc.html
3. mobile.html
4. mobile-portrait.html
5. mobile-landscape.html

추가된 기능:
- 시작 화면에서 PC / 세로 연주 / 가로 2페이지 모드 분기
- PC 화면에서 세로/가로 연주 모드 바로 이동
- 연주 모드 X 닫기 후 원래 화면 복귀
- 연주 모드 좌우 스와이프 = 현재 곡 악보 페이지 이동
- 곡 이동은 하단바 이전곡/다음곡 버튼으로 직접 선택
- 가로 모드 1장/2장 보기 전환
- 화면 꺼짐 방지 Wake Lock 적용, 실패 시 안내
- 곡별 악보관리 안 파일명 규칙 안내
- 관리도구 안 파일명 생성 도우미
- 관리도구 안 AI 콘티 추천 설정 UI

아직 2차에서 할 작업:
- DB 구조 확장
- 다중 Key/악보 버전관리 실제 테이블 연결
- 콘티별 선택 악보 저장
- AI 추천 실제 호출
