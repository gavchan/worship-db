Phase49 - 찬양곡 추가/악보 일괄등록 자동분석 + 관리도구 정리

적용 내용
1. 찬양곡 추가 모달에 악보 드래그앤드롭 자동분석 영역 추가
   - 파일명 예: 또 하나의 열매를 바라시며_Bb_기본-1.png
   - 자동 추출: 곡명 / Key / 악보버전 / 페이지
   - 새 곡 저장 시 선택된 악보도 이어서 업로드

2. Storage 파일명 안전 유지
   - 사용자가 올린 한글 파일명은 분석용으로만 사용
   - 실제 Storage 저장은 기존 안정 원칙대로 숫자 파일명 사용
   - song_id 폴더 + 숫자 파일명 구조 유지

3. 기존 악보가 없을 때 불필요한 기존악보 영역 노출 최소화
   - 등록된 악보가 없으면 안내만 간단히 표시
   - 악보 삭제 버튼은 실제 악보가 있을 때만 동작

4. 관리도구 중복 메뉴 정리
   - 찬양곡 수정 메뉴 제거: 메인 찬양곡 카드 수정과 중복
   - 콘티 기록 수정 메뉴 제거: 메인 콘티 기록 수정과 중복

5. 악보 일괄등록 개선
   - 곡명_Key_악보버전-페이지 형식 자동분석 강화
   - DB에 없는 곡은 새 곡으로 등록 가능
   - 기존 곡과 매칭되면 기존 곡에 악보 추가
   - 실제 저장 파일명은 숫자 파일명 유지

6. 곡별 악보관리 선택 갱신 보강
   - 왼쪽 검색/선택 변경 시 오른쪽 목록을 즉시 로딩 상태로 초기화 후 재조회

유지한 원칙
- 기존 DB 구조 변경 없음
- Storage 숫자 파일명 유지
- 새창/popup/window.open 추가 없음
- 인뷰/인플레이어 원칙 유지
- 기존 기능 삭제는 중복 관리 메뉴에 한정
