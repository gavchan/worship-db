Phase 25 - 악보 연결 점검 유틸 추가

추가 파일:
- score-audit.html

관리도구 추가 위치:
- PC 관리도구 > 악보 관리 > 악보 연결 점검
- 모바일 관리도구 > 악보 연결 점검

기능:
- 전체 songs DB와 Supabase Storage(scores 버킷)를 비교
- 한 곡에 여러 악보 파일/그룹이 연결된 곡만 필터링 표시
- 악보 미리보기
- 개별 악보 파일 선택 삭제
- song_score_files 기록 정리 시도
- 삭제 후 has_score/status 재정리

주의:
- 자동 삭제는 하지 않음
- 사용자가 미리보기로 확인 후 파일별로 직접 삭제
