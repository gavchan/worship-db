Phase32 - 악보 로딩 엔진 통합

수정 목적:
- PC / 모바일 / 공유 화면이 서로 다른 방식으로 악보를 찾으면서 "악보 있음"인데도 파일을 못 찾는 문제를 줄입니다.

핵심 수정:
1. song_score_files DB 기록을 먼저 확인합니다.
2. Supabase Storage의 scores/{song_id}/ 하위 파일을 재귀적으로 확인합니다.
   - scores/{song_id}/파일
   - scores/{song_id}/versions/{version_id}/파일
   같은 중첩 구조도 찾습니다.
3. DB 기록과 실제 Storage 파일을 대조해서 존재하는 이미지 파일만 화면에 넘깁니다.
4. DB 기록이 없어도 Storage에 실제 이미지가 있으면 보여줍니다.
5. PC / 모바일 / 공유 연주 화면의 scoreUrl 생성 방식을 scorePath() 기준으로 통일했습니다.

주의:
- Storage 파일명은 한글로 강제 변경하지 않습니다.
- 실제 파일명은 기존 숫자/영문 안전 파일명을 유지합니다.
- 곡명 / Key / 버전 / 페이지 의미 정보는 DB 기준으로 관리합니다.
