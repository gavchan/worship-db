Phase7 모바일 연주모드 오버레이 정리

기준 파일:
- worship-db-phase6-dnd-youtube-card-conti-stay-fix.zip

수정 파일:
- mobile.html

변경 내용:
1. 모바일 연주모드 화면을 악보 전체화면 중심으로 정리했습니다.
2. 상단 왼쪽에 투명 오버레이로 [1장보기] [2장보기]를 배치했습니다.
3. 상단 오른쪽 X도 투명 오버레이로 악보 위에 배치했습니다.
4. 하단에는 콘티 곡 제목 링크만 투명 레이어로 표시합니다.
5. 하단 맨 오른쪽에 [화면잠금]을 배치했습니다.
6. 이전곡/다음곡 전용 버튼, 별도 페이지 이동 버튼은 추가하지 않았습니다.
7. 악보 페이지 이동은 기존 좌우 스와이프 흐름을 유지합니다.
8. 화면잠금은 기존 Wake Lock 기능을 토글하는 방식으로 연결했습니다.

유지한 기능:
- 콘티 곡 제목을 누르면 해당 곡으로 이동
- 좌우 스와이프로 페이지 이동
- 마지막 페이지 다음 스와이프 시 다음 곡 이동
- 첫 페이지 이전 스와이프 시 이전 곡 이동
- 기존 콘티 드래그앤드롭
- 기존 모바일 유튜브 주소 보강
- 기존 ↑ ↓ 백업 버튼

충돌 확인 및 처리:
- 기존 viewer-top 닫기 버튼은 삭제하지 않고, 연주모드에서는 CSS로 숨겼습니다.
  다른 악보 보기/일반 뷰어에서 쓰일 수 있어 코드를 제거하지 않았습니다.
- orientation 선택 모달 코드는 삭제하지 않았습니다.
  현재 openSongViewer는 자동으로 모바일 연주모드를 시작하지만, 함수 참조가 남아 있어 즉시 삭제하면 충돌 가능성이 있습니다.
- viewer.performance 클래스를 닫을 때 제거하던 부분은 다음 재진입 때 연주모드 스타일이 빠질 수 있어 show만 제거하도록 수정했습니다.

삭제하지 않은 이유:
- 세로/가로 전용 관련 함수와 모달은 현재 직접 버튼에서는 쓰지 않더라도 내부 함수 참조가 연결되어 있습니다.
- 다음 단계에서 호출 관계를 한 번 더 정리한 뒤 안전하게 삭제하는 것이 좋습니다.
