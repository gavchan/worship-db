Worship DB Phase7 4-4 관리도구/일괄관리/순차편집기 정리

적용 내용
1. PC 관리도구를 운영도구 / 일괄관리 / 고급도구·초기구축 영역으로 재정리했습니다.
2. 위험하거나 한 번만 쓰는 sync/launch/check 계열은 기본 접힘 영역으로 이동했습니다.
3. 악보 일괄등록기에 멀티 Key/BPM 입력 및 개별 수정 필드를 추가했습니다.
4. 악보 일괄등록기에서 자동 분석 → 미리보기 → 개별 수정 → 최종 적용 흐름을 강화했습니다.
5. 최종 업로드 전 원본 DB 변경 경고를 추가했습니다.
6. 순차편집기에 멀티 Key/BPM 입력을 추가했습니다.
7. 순차편집기에 이전 작업 이후부터 이어하기 기능을 추가했습니다.
8. 순차편집기 저장 시 원본 DB 수정 경고를 추가했습니다.

주의
- extended columns(keys, bpm_min, bpm_max, bpm_label)은 Phase7 4-1 SQL 적용 전에는 저장 시도만 하고 기존 key/bpm 저장으로 fallback됩니다.
- 실제 완전한 악보버전/페이지 ID 기반 저장은 Supabase 스키마 적용 후 별도 연결이 필요합니다.
