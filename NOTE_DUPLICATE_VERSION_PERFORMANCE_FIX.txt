같은 곡명 다른 버전이 공유/연주 화면에 같이 나오는 문제 수정

적용 내용
1. 공유 화면 share.html
- 콘티 로딩 시 song_id 인덱스 기준을 유지합니다.
- 같은 곡명이 여러 버전으로 들어온 기존 기록은 연주 화면에서 첫 곡만 남기고 중복 표시를 막습니다.

2. 모바일 메인 mobile.html
- buildContiSongsFromHistory()에서 이름 fallback 없이 song_id 기준만 사용합니다.
- 같은 곡명 중복 버전은 연주용 contiSongs 생성 단계에서 제거합니다.
- 모바일 콘티 수정/저장 시에도 같은 곡명 중복을 한 번 더 정리합니다.

3. PC pc.html
- 콘티 저장 직전에 같은 곡명 중복을 정리해 새 기록에 중복 버전이 남지 않게 했습니다.

주의
- 같은 제목을 의도적으로 두 번 넣어야 하는 콘티는 현재 중복 정리 규칙 때문에 첫 번째 항목만 남습니다.
