드림찬양단 Worship DB - 2차-A 적용 안내

이번 버전 목적:
- 관리도구 실동작 복구/연결
- 모바일 관리도구에서 기존 일괄등록기/순차편집기를 같은 화면 안에서 열기
- 파일명 생성 도우미 오류 수정
- 악보 일괄 업로드 화면에 파일명 규칙 안내/생성 도우미 추가
- 곡별 악보 관리/전체악보 관리/AI 설정 UI 유지

교체 권장 파일:
1. index.html
2. pc.html
3. mobile.html
4. mobile-portrait.html
5. mobile-landscape.html
6. score-upload.html

확인 순서:
1. / 로 접속해서 PC/세로/가로 분기 확인
2. /pc.html 에서 관리도구가 새창이 아니라 같은 화면 안에서 열리는지 확인
3. /mobile.html → 관리도구 → 악보 일괄등록기 확인
4. /mobile.html → 관리도구 → 순차 편집기 확인
5. /mobile.html → 관리도구 → 파일명 생성 도우미 확인
6. /mobile.html → 관리도구 → 곡별 악보 관리에서 업로드/보기/삭제 확인

주의:
- 이번 버전은 기존 DB 구조는 바꾸지 않습니다.
- 다중 Key/악보 버전관리/콘티별 선택 악보 저장은 2차-B에서 진행합니다.
