Worship DB Phase 4-1 적용 내역

범위:
1) 모바일 콘티 유튜브보기는 지정 플레이리스트를 내부 팝업 모달로 표시
2) 곡별 유튜브보기는 기존 인필드/모달 흐름 유지
3) 전체화면 연주모드 상단 정보 UI 제거, X 버튼만 악보 위 레이어로 유지
4) 전체화면 연주모드 하단에 투명한 한 줄 곡 이동 레이어 배치
5) 하단 곡 글자 클릭 시 해당 곡으로 이동
6) 모바일 관리도구 진입 암호 보호 추가, 비밀번호 1955

테스트:
- mobile.html inline JavaScript 문법 검사 통과
- pc.html inline JavaScript 문법 검사 통과
- 콘티 유튜브보기 고정 URL 임베드 변환 로직 확인
- 관리도구 암호 모달 연결 확인

기존 대비 사라지거나 바뀐 부분:
- 모바일 전체화면 연주모드에서 기존 하단 조작바/곡정보바는 화면에서 숨김 처리됨
- 모바일 콘티 유튜브보기는 더 이상 콘티 안의 첫 번째 곡 유튜브를 찾지 않고 지정 플레이리스트만 염
- PC 화면 구조와 곡별 인필드 영상보기는 유지

주의:
- 실제 방향고정/주소창 숨김은 브라우저 권한 및 기기 정책 영향을 받음
- 4-2차에서 모바일 찬양곡 카드 확장 UX와 전체화면 캐시 최적화를 진행 예정
