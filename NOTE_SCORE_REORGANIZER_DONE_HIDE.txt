악보 재배치 유틸 개선

- '이 곡 파일 정리 실행' 또는 '현재 파일을 DB 기록으로 정리' 완료 시 해당 곡을 정리 완료 목록에 기록합니다.
- 정리 완료된 곡은 기본 곡 목록에서 숨겨져 다시 작업할 필요가 없습니다.
- 상단 '완료곡 보기'를 켜면 정리 완료된 곡도 다시 볼 수 있습니다.
- 상세 화면에서 '정리 완료 처리'와 '완료 표시 해제'를 수동으로 사용할 수 있습니다.
- 이 완료 기록은 브라우저 localStorage 기준입니다. 다른 브라우저/기기에서는 다시 보일 수 있습니다.
- Storage 실제 파일명은 기존처럼 숫자/영문 안전 파일명으로 유지합니다.
- JSON 파일을 Storage에 업로드하지 않습니다.
