Worship DB Phase8 안전 UI 정리

기준 파일:
- worship-db-phase6-responsive-conti-hero-fix.zip

수정 파일:
- mobile.html
- pc.html
- share.html

이번 1차에서 반영한 내용:
1. 명칭 정리
- 이번 주 콘티/이번주 콘티 → 콘티 순서 중심으로 정리
- 주일 기록/주일기록 → 콘티 기록
- 전체화면 연주 → 연주화면
- 전체 악보/전체악보 → 한눈에보기

2. 모바일 콘티 순서 화면 정리
- 콘티 순서 리스트를 순번/곡명/Key/BPM/악보 아이콘/영상 아이콘/수정 중심으로 단순화
- 악보 있음: 흰색 아이콘
- 악보 없음: 빨강 아이콘
- 영상 있음: 흰색 아이콘
- 영상 없음: 빨강 아이콘
- 오른쪽 뷰어 상단의 중복 콘티수정/악보 크게보기 버튼 제거
- 곡별 뷰어 안에서는 악보/영상 전환만 유지

3. 콘티 편집 목록 정리
- 드래그 핸들을 오른쪽으로 이동
- 위/아래 화살표 버튼 제거
- 드래그앤드롭 정렬은 유지

4. 데스크 모드 1차 정리
- 상단 탭의 주일기록 명칭을 콘티기록으로 변경
- 현재 콘티/콘티 선택 없음 바 제거
- 콘티 작성 모달의 선택곡 목록에서 화살표 제거, 오른쪽 삼줄 핸들 유지

5. 공유 화면 1차 정리
- 공유 화면 상단 메뉴를 유튜브/연주/한눈/공유로 정리
- 작은 폭에서는 텍스트형 메뉴로 전환

이번 1차에서 일부러 건드리지 않은 것:
- 메모 저장 구조
- 메모 히스토리 불러오기
- 다른버전 악보추가 데이터 구조
- 현재버전 수정/악보 업로드 구조
- 연주화면 하단 색상 규칙
- 한눈에보기 상세 구조

주의:
- 데이터베이스 스키마 변경 없음
- Supabase 저장/불러오기 함수 변경 없음
- 기존 드래그앤드롭 함수는 유지
- 화살표 이동 함수는 삭제하지 않고 남겨두었지만 버튼에서는 제거함
