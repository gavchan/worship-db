# 연주모드 방향 선택/고정 긴급 패치

## 교체 파일
- mobile.html
- mobile-portrait.html
- mobile-landscape.html

## 변경 내용
- 연주모드 버튼을 누르면 바로 진입하지 않고 방향 선택 팝업 표시
- 세로 연주모드 / 가로 연주모드 선택
- 선택한 방향으로 화면 방향 고정 시도
- 연주모드 중 화면 꺼짐 방지 유지
- 연주모드 종료(X) 시 방향 고정 해제 및 전체화면 해제 시도
- 가로 선택 시 1장/2장 보기 버튼 표시
- 세로 선택 시 한 화면 고정형 레이아웃 유지

## 주의
- iOS/Safari나 일부 브라우저는 화면 방향 잠금을 제한할 수 있음
- 실패 시에도 연주모드는 정상 진입하며, 기기 자체 회전잠금을 같이 사용하면 안정적
