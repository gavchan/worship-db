Worship DB Phase 5 적용 안내

기준 파일: worship-db-phase4-2.zip
수정 파일: mobile.html

주요 변경:
1. 콘티 상단의 [유튜브 보기] [전체화면 연주] [전체 악보]는 유지했습니다.
2. 콘티 아래 곡별 패널의 전체화면 버튼은 콘티 전체 연주가 아니라 해당 곡 악보 크게보기로 분리했습니다.
3. 곡별 패널에 [콘티수정]을 추가했습니다.
4. 이번 주 찬양 흐름 각 곡에 [수정] 버튼을 추가했습니다.
5. 콘티수정은 곡 DB 원본을 바꾸지 않고, 이번 콘티 안에서 Key/BPM/악보버전/영상링크/메모를 덮어씁니다.
6. 전체화면 연주모드의 X 레이어, 하단 투명 곡목록, 곡목록 클릭 이동, 스와이프, 방향고정, 캐시는 유지했습니다.
7. 모바일 상단 앱다운로드는 하나만 남기고, nav 안의 중복 앱다운로드 링크를 제거했습니다.
8. 찬양곡 데이터베이스 확장 카드의 덱 구조를 왼쪽 정보 / 오른쪽 작은 악보 안내 형태로 보강했습니다.

주의:
- 콘티수정 값은 현재 브라우저 localStorage에 저장됩니다. DB 스키마 변경 없이 안전하게 붙인 임시/현장형 방식입니다.
- 서버 DB에 콘티별 악보버전/Key를 영구 저장하려면 별도 schema가 필요합니다.
