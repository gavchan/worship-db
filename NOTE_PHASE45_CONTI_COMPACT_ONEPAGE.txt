PHASE45 콘티 수정 모달 한 화면 compact 정리

변경 파일:
- mobile.html

변경 내용:
- 콘티 곡 설정 모달을 한 화면 안에 들어오도록 재배치
- 왼쪽: 현재 곡 악보 미리보기 크게 고정
- 오른쪽: 곡명 / Key / BPM / 버전 / 영상링크 / 메모 compact 입력
- 전체 모달 스크롤 최소화
- 악보 영역만 내부 스크롤 중심으로 동작
- 악보 보기 버튼 제거: 수정 화면 안 미리보기 중심
- 악보 목록 표시 영역 숨김: 공간 낭비 제거
- 업로드 기능은 유지
- 초기화 / 취소 / 저장 유지

유지한 원칙:
- 기존 DB 구조 변경 없음
- Storage 숫자 파일명 변경 없음
- 새창 / popup / window.open 추가 없음
- 기존 함수명과 input id 유지
- 업로드, 저장, 초기화 기능 유지
