Phase31: 연주 화면 유령 악보/깨진 이미지 렌더 방지

적용 내용:
- Supabase Storage 공개 URL 생성 시 경로를 안전하게 인코딩합니다.
- listScores() 결과에서 이미지 파일(png/jpg/jpeg/webp/gif)만 사용합니다.
- 연주 화면/공유 화면에서 악보 이미지 로딩 실패 시 깨진 이미지 카드를 즉시 제거합니다.
- 한 곡의 모든 페이지가 깨졌을 때만 '악보 파일 확인 필요' 안내를 표시합니다.
- 기존 관리도구와 기존 기능은 삭제하지 않았습니다.

주의:
- 실제 Storage/DB 데이터는 자동 삭제하지 않습니다.
- 깨진 항목을 화면에서 보이지 않게 막는 보호막입니다.
- 실제 파일 정리는 관리도구의 악보 재배치/삭제 유틸에서 진행하세요.
