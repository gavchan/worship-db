Worship DB Phase 4-2 적용 안내

기준 파일: phase4-1 수정본
주요 변경 파일: mobile.html

적용 내용
1. 모바일 찬양곡 섹션 카드 축소
   - 3열 구조 유지
   - 기본 카드에는 곡이름, Key, BPM, 악보/영상 유무 아이콘, 콘티추가만 표시
   - 악보/영상 아이콘은 있음=흰색, 없음=빨강 계열로 표시

2. 모바일 찬양곡 섹션 카드 확장
   - 카드 선택 시 바로 콘티 추가하지 않고 같은 그리드 안에서 확장
   - 확장 카드는 3열 전체 폭을 차지하며 2줄 카드 정도의 큰 덱처럼 표시
   - 확장 카드 안에 세부정보, 콘티추가, 악보보기, 영상보기, 수정, 이전/다음, 삭제 아이콘 배치

3. 곡별 악보 크게보기
   - 모바일 찬양곡 섹션의 악보보기는 해당 곡 전체 악보만 크게 표시
   - 페이지 번호 표시
   - 이전쪽/다음쪽 이동
   - 이전곡/다음곡 이동
   - 콘티 전체 연주모드와 분리

4. 전체화면 연주모드 캐시
   - 전체화면 연주모드 진입 시 콘티 곡들의 악보 이미지를 백그라운드로 미리 로딩
   - 일반 탐색 화면에서는 전체 악보 선로딩하지 않음
   - X 종료 시 메모리 캐시 정리

기존에서 바뀐 부분
- 모바일 찬양곡 카드 클릭 동작이 '콘티 추가/홈 미리보기 이동'에서 '카드 확장'으로 변경됨
- 콘티 추가는 카드 안의 '콘티추가' 버튼으로만 실행됨
- 모바일 찬양곡 기본 카드의 메모/태그 노출은 기본 상태에서 숨김 처리됨

유지되는 부분
- PC 화면 구조는 변경하지 않음
- 콘티 유튜브 팝업은 phase4-1 기준 유지
- 곡별 유튜브 인필드/모달 재생 흐름 유지
- 전체화면 연주모드 스와이프/방향 고정 유지
- 관리도구 비밀번호 1955 유지
