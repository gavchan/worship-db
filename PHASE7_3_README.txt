Worship DB Phase 7-3
공유 악보/연주 + PDF 업로드 검증 패치

적용 기준
- phase7-2 backup/rollback 운영본 기준
- 기존 fullscreen, 스와이프, 방향고정, 유튜브, 캐시 엔진은 건드리지 않음

변경 파일
- share.html
- score-upload.html

share.html 변경
- 공유 페이지 제목을 YYYY년 M월 D일 콘티 형식으로 정리
- 공유 페이지에 악보 이미지 표시 추가
- 곡별 악보 없음 표시 추가
- 공유 페이지에서도 전체화면 악보/연주 진입 가능
- 전체화면 안에서 오른쪽 위 X, 하단 투명 곡목록, 좌우 스와이프, 방향키 이동 지원
- 읽기 전용 구조 유지: 수정/삭제/관리도구 없음

score-upload.html 변경
- PDF는 직접 연주용 업로드하지 않고 이미지 변환 필요 상태로 표시
- PDF 파일은 업로드 시작 시 제외하고 안내 알림 표시
- JPG/PNG는 기존 업로드 흐름 유지
- 파일명 안내에 PDF 이미지 변환 방향 추가

주의
- PDF 실제 페이지별 이미지 변환 기능은 서버/API 또는 별도 변환 도구가 필요하므로 이번 차수에서는 직접 변환을 넣지 않음
- 공유 페이지 악보 표시는 Supabase Storage scores 버킷의 공개 이미지 URL 기준
