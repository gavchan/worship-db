Phase 38 - UI 3단계: 수정/연주/공유 화면 인뷰 원칙 + 공간 절약 정리

기준: phase37

핵심 원칙:
- 악보/유튜브/관리도구는 새창, 새탭, window.open 없이 현재 화면 안에서만 표시
- DB/Storage 악보 로딩 엔진은 건드리지 않음
- 기존 기능 삭제 없음
- 화면 상단/하단/모달의 불필요한 세로 공간을 줄이고 버튼 영역을 압축

변경 내용:
1. pc.html
   - 관리도구 새 탭 링크 제거, 현재 화면 안 iframe 유지
   - 유튜브 외부 열기 링크 제거, 인플레이어 안내 뱃지로 대체
   - openExternalUrl는 새창을 열지 않고 안내만 표시
   - 도구/유튜브/모달 헤더와 하단 액션바 공간 축소

2. mobile.html
   - 유튜브 외부 열기 링크 제거
   - 관리도구 새 탭 버튼 제거
   - 모바일 도구 iframe 높이와 모달 헤더/하단 버튼 공간 정리

3. share/mobile-portrait/mobile-landscape/index
   - target=_blank 속성 차단 처리
   - 외부 새창 클릭 방지 가드 추가

주의:
- 이 단계는 UI 안전 정리이며, song_id/storage_path 로더 구조는 변경하지 않았습니다.
