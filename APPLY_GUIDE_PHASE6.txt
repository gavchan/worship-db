Worship DB Phase 6 적용 안내

수정 기준
- phase5 수정본 위에 적용한 보강 작업입니다.
- 전체화면 X 레이어, 하단 곡목록 클릭 이동, 스와이프, 방향고정, 악보 캐시, 곡별 인필드 유튜브, 콘티 유튜브 팝업, 관리도구 비밀번호 1955는 유지했습니다.

변경 파일
- mobile.html
- pc.html
- share.html 신규 추가

변경 내용
1. 이번주 콘티 기준 수정
- 모바일 메인 명칭을 “이번주 콘티”로 정리했습니다.
- 오늘 날짜가 포함된 주 월요일~주일 범위의 콘티를 우선 표시합니다.
- 해당 주 콘티가 없으면 최신 콘티를 표시합니다.

2. 콘티별 수정값 분리
- 콘티 곡 설정 저장을 콘티 단위 localStorage 키로 분리했습니다.
- 같은 곡이라도 다른 주 콘티에서 수정한 Key/BPM/악보버전/영상링크/메모가 이번주 콘티에 섞이지 않도록 했습니다.
- 내부 저장 키는 콘티ID + 곡ID/순서 기반입니다.

3. 주일기록 공유
- 모바일 주일기록 카드에 카톡공유 버튼을 추가했습니다.
- PC 주일기록 상세에도 공유 버튼을 추가했습니다.
- 공유는 Web Share API를 먼저 사용하고, 실패하면 링크 복사/새 창 열기로 대체합니다.

4. 공유 전용 페이지
- share.html을 새로 추가했습니다.
- share.html?id=콘티ID 형식으로 콘티를 읽기 전용 표시합니다.
- 표시 내용: 날짜, 콘티 제목, 곡 순서, 곡명, Key, BPM, 악보/영상 여부, 메모.
- 하단에 “홈페이지 방문” 버튼을 추가했습니다.

주의
- 카카오 공식 SDK 키는 아직 연결하지 않았습니다. 현재는 모바일 브라우저의 기본 공유창을 통해 카카오톡으로 공유할 수 있고, 안 되면 링크 복사로 대체됩니다.
- 서버 DB 스키마 변경은 하지 않았습니다.
