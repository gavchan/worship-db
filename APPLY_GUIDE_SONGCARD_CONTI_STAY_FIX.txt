# 찬양곡 카드 클릭 / 콘티 이동 수정 안내

기준 파일: worship-db-phase6-dnd-youtube-fix.zip

## 수정 파일
- mobile.html

## 수정 내용
1. 찬양곡 카드 전체 클릭은 3x2 세부정보 패널을 여는 흐름으로 유지합니다.
2. 콘티추가 버튼만 콘티에 곡을 추가합니다.
3. 콘티추가 후 `이번 주 콘티` 화면으로 자동 이동하던 `showSection('home', ...)` 호출을 제거했습니다.
4. 콘티추가 후 현재 찬양곡 화면을 유지하고, 내부 콘티 목록만 `renderHome()`으로 갱신합니다.
5. 확장 패널 내부 버튼들에 `event.stopPropagation()`을 적용해 카드 클릭 이벤트와 버튼 이벤트가 섞이지 않게 했습니다.

## 유지되는 기능
- 콘티 드래그앤드롭 순서 변경
- 기존 ↑ ↓ 백업 버튼
- 모바일 유튜브 주소 변환 보강
- 찬양곡 카드 3x2 확장 패널

## 원본에서 사라지는 동작
- 찬양곡 화면에서 콘티추가를 누른 뒤 자동으로 이번 주 콘티 화면으로 이동하던 동작
