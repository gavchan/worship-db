Worship DB Final Stabilized Build

최종 사용 가이드

이번 파일은 1~10단계 기능을 묶고, 마지막 링크/문법/점검 보강까지 적용한 최종 안정화판입니다.

바로 열기

처음 화면 PC 관리 세로 연주 가로 2페이지 실행 점검 백업/복원 DB 점검

적용된 핵심 기능

곡 상세화면
카드 클릭은 상세 보기, + 버튼은 콘티 추가로 분리했습니다.
Score Group
같은 곡/Key/버전의 여러 페이지를 한 그룹으로 처리합니다.
연주모드
세로 1장, 가로 2장 연속 보기, 좌우 스와이프 전용 흐름입니다.
콘티 재사용
이전 예배 기록을 복사하거나 바로 연주할 수 있습니다.
빠른 점프
연주 중 하단 정보 영역 길게 누르기로 원하는 곡으로 이동합니다.
전체악보 PDF
이번주 전체악보 PDF 업로드와 미리보기 구조를 넣었습니다.
백업/복원
찬양곡, 콘티, 설정을 JSON으로 내보내고 가져올 수 있습니다.
점검 도구
실행 점검과 DB 연결 점검 페이지를 추가했습니다.

테스트 순서

  1. index.html을 열고 실행 점검으로 필수 페이지를 확인합니다.
  2. PC 관리 화면에서 악보 버전관리, 백업/복원, DB 점검 버튼이 열리는지 확인합니다.
  3. 모바일 세로 화면에서 곡 카드 클릭과 + 버튼 동작이 분리되는지 확인합니다.
  4. 콘티에 2장 이상 악보 곡을 넣고 연주모드에서 페이지가 이어지는지 확인합니다.
  5. 가로모드에서 [1][2] → [2][3] 흐름으로 넘어가는지 확인합니다.
  6. 연주 중 하단 정보를 길게 눌러 빠른 점프 목록이 뜨는지 확인합니다.
  7. 백업 JSON을 한 번 내려받아 보관합니다.

롤백 기준

문제가 생기면 가장 가까운 단계 zip으로 되돌리면 됩니다. 이번 최종판 직전 기준은 worship-db-step10-launch-check-links.zip입니다.

실제 Supabase에 적용하기 전에는 반드시 JSON 백업을 먼저 내려받으세요.
