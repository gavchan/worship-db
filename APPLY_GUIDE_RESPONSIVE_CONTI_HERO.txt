# 반응형 콘티 상단 카드 수정 안내

수정 파일
- mobile.html
- share.html

변경 내용
- 모바일 본체 이번주 콘티 상단 카드가 좁은 폭/낮은 높이에서 자동 압축됩니다.
- 공유 화면 상단 카드도 같은 기준으로 압축됩니다.
- 큰 카드형 버튼은 좁은 화면에서 작은 pill 버튼 줄처럼 보입니다.
- 곡 목록이 첫 화면에 더 빨리 보이도록 설명문과 버튼 높이를 줄였습니다.

유지한 기능
- 유튜브 보기
- 전체화면 연주
- 전체 악보
- 콘티 공유
- 공유 페이지 악보 보기/연주화면
- 기존 함수 연결

삭제한 기능
- 없음

충돌 확인
- 기능 함수는 바꾸지 않고 CSS/레이아웃 중심으로 수정했습니다.
- share.html은 공유 페이지 안에서도 빠르게 연주/악보로 들어갈 수 있게 상단에 작은 빠른 버튼 줄을 추가했습니다.
